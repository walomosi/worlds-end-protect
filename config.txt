# GuardKit 守护配置
# 语法说明：
#   <进程名>=<完整启动路径>   —— 要守护的教学软件客户端（进程名不含 .exe，与任务管理器一致）
#   PROTECT=<路径>            —— 要收紧写权限的配置文件/目录（可多行，仅 SYSTEM/管理员可写，学生只读）
#   WHITELIST=<路径通配>      —— 应用白名单额外允许路径（可多行，AppLocker 用；系统目录/Program Files 默认已允许）
#   SCANPATH=<目录>           —— 恶意文件监控目录（可多行；不配则默认扫描 下载/桌面/临时目录）
#   WATCH_MS=<毫秒>           —— 巡检间隔（500-30000，默认 2000）
# 以 # 或 // 开头的行是注释。
#
# 示例（极域电子教室学生端，请按本机实际进程名与安装路径修改）：
# StudentMain=C:\Program Files (x86)\JingCheng\Client\StudentMain.exe
# PROTECT=C:\Program Files (x86)\JingCheng\Client\Config
# WHITELIST=C:\Program Files (x86)\JingCheng\*
# SCANPATH=C:\Users\Public\Downloads
#
# 如何确认真实进程名：开机运行学生端后，任务管理器 -> 详细信息 -> 看进程名（如 StudentMain.exe）
# 如何确认路径：任务管理器选中进程 -> 右键 -> 打开文件所在位置

# ===== 在这里配置你的教学软件 =====

# PROTECT=C:\Program Files (x86)\JingCheng\Client\Config
