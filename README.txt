GuardKit v3 — 教学软件守护 + 恶意程序防线
==========================================

作用
----
1. 防止学生通过"结束客户端进程 / 修改配置 / 替换程序"等方式绕过教学软件管控。
2. v3 新增：防止学生下载病毒/破解工具来绕过管控——下载的可执行文件自动隔离，
   AppLocker 应用白名单让未白名单的程序根本无法运行。

防线总览
--------
- 三重自启：Windows 服务 + 计划任务（每分钟检查，SYSTEM 权限）+ 开机自启 Run 键
- 三副本环形互守：GuardKitA/B/C.exe 互相拉起，学生难以一次找全
- 配置加密：部署后 config.txt 转为 config.bin（AES-256 加密），篡改/读取需逆向 exe
- 完整性校验：每 5 分钟比对 exe SHA256 基准，自身被替换自动从备份恢复并重启
- 服务崩溃自动重启（sc failure 5 秒）
- 配置目录权限巡检：每 5 分钟 icacls 收紧，仅 SYSTEM/管理员可写
- [v3] 下载/临时目录监控：每 30 秒扫描新出现的 exe/msi/scr/bat/cmd/ps1/vbs/js/jar/dll，
  自动移入 C:\ProgramData\GuardKit\quarantine\ 隔离区并记日志
- [v3] AppLocker 应用白名单（系统级）：只允许 系统目录 + Program Files + 配置 WHITELIST
  的程序运行，学生下载的破解工具/病毒 exe 直接无法启动（Win10/11 Pro/Enterprise、Server）

使用（老师/机房管理员）
-----------------------
1. build.cmd 编译（无需 VS）
2. 编辑 config.txt 模板，填写教学软件客户端进程名与路径，可选配置：
     StudentMain=C:\Program Files (x86)\...\StudentMain.exe
     PROTECT=C:\Program Files (x86)\...\Config
     WHITELIST=C:\Program Files (x86)\...\*      （AppLocker 额外允许路径）
     SCANPATH=C:\Users\Public\Downloads          （恶意文件监控目录，默认下载/桌面/临时）
3. 以管理员身份运行 bin\GuardGui.exe（或 install.cmd）
4. 界面中点击"一键部署"，完成三副本+服务+计划任务+加密
5. "恶意程序防线"页签：先"生成策略(预览)"查看 XML，确认后"应用白名单"（系统级，慎用）

日常维护（图形界面）
--------------------
- 状态页：服务状态 / 副本存活数 / 目标进程实时状态
- 守护目标页：增删改目标与保护路径，保存后自动重启服务
- 恶意程序防线页：白名单路径/扫描目录管理 + AppLocker 策略生成与应用
- 日志页：实时查看 C:\ProgramData\GuardKit\guard.log
- 卸载：界面"卸载"按钮，或 uninstall.cmd

AppLocker 应用白名单说明
------------------------
- 应用后未列入白名单的 exe/msi/脚本一律无法运行（白名单模式，无需显式拒绝规则）
- 默认白名单：C:\Windows\*、Program Files、Program Files (x86)
- 教学软件所在目录请务必加入 WHITELIST，否则应用白名单后客户端无法启动
- 先在机房单台机器"生成策略(预览)"验证，确认教学软件全在白名单内再批量应用
- 撤销：管理端组策略编辑器 -> Windows 设置 -> 安全设置 -> 应用程序控制策略 -> AppLocker，
  删除策略或改回"未配置"；也可用 Get-AppLockerPolicy -Effective -Xml 导出备份后恢复

还原明文配置（需要重新部署时）
------------------------------
用 GUI 修改并保存会写回明文 config.txt（部署前状态）；
一键部署后自动加密并删除明文。如需完全重置，卸载后从源码目录重新部署。

局限（如实告知，配合管理制度）
------------------------------
- 学生自带设备（手机热点/个人电脑）绕开机房网络：本工具管不到
- 物理绕过（PE 启动、清 CMOS、拆机）：需机箱锁/USB 封堵/机房制度
- 系统公开提权漏洞未打补丁：任何权限方案都失效，务必保持补丁更新
- 对抗专业级逆向/驱动级攻击：超出本工具范围（需驱动签名方案）
- AppLocker 依赖系统服务（AppIDSvc）与白名单完整性：学生以管理员权限登录时可改策略，
  因此学生机必须全部使用标准用户账号（无管理员权限）
结论：本工具把绕过成本提高到普通学生乃至一般技术爱好者难以短时突破的水平，
"绝对无法破解"不存在，请配合补丁更新、标准用户权限与物理管理。
